# As versoes sao exatas, e nao ">=", de proposito.
#
# Com ">=" cada "pip install" resolve o que houver de mais novo no dia, entao
# a maquina do desenvolvedor, o CI e a imagem que vai para producao podem
# rodar tres programas diferentes a partir do mesmo commit. Isso ja custou
# caro: o CI resolveu FastAPI 0.138, que mudou a estrutura interna de
# include_router, e um teste passou a falhar por um motivo que nao existia em
# lugar nenhum do codigo -- quase parando um deploy.
#
# Os numeros abaixo sao os que o backend roda de fato: suite completa,
# streaming SSE e o fluxo de agentes ponta a ponta. Subir qualquer um deles e
# uma decisao deliberada -- altere aqui, rode a suite, deixe o CI confirmar.

# Core Agent Framework

# e "agent_framework.openai" -- e nao o guarda-chuva "agent-framework". O

# ele resolve os sub-pacotes soltos, e os mais novos ja exigem um core mais
# novo do que o guarda-chuva pinado permite -- um conflito insoluvel.
